# Dúvidas do estudo do repositório

Registro das dúvidas surgidas na leitura do [guia de estudo](../relatorios/2026-11-18-guia-de-estudo.html), com as
respostas, um arquivo por seção do guia, na ordem do sumário. Cada resposta
indica de onde vem: um arquivo do repositório (número que se pode rodar de
novo) ou conhecimento geral de telecomunicações. No fim do estudo, estes
arquivos viram um relatório em HTML em `docs/relatorios/`.

Os números citados saem de `python3 tools/analysis/lora_budget.py` na `main`
de 10/11 (`b830c95`). A numeração das perguntas é contínua entre os arquivos.

A partir de 18/11 o guia é o [de 18/11](../relatorios/2026-11-18-guia-de-estudo.html),
com a ADS-B da ground, a página central e as Etapas A e B. As seções têm os
mesmos números do [de 10/11](../relatorios/2026-11-10-guia-de-estudo.html), e
as dúvidas já registradas continuam valendo. Para o estimador por dentro:
[o estimador antes e depois da Etapa A](../relatorios/2026-11-18-estimador-antes-depois-etapa-a.html).
